# Diagnostico Node.js

Este proyecto tiene un archivo JavaScript simple que muestra informacion de Node.js usando `console.log(...)` y `process`.

## Como ejecutar

```bash
node diagnostico.js prueba
```

Tambien se puede usar:

```bash
npm run diagnostico
```

## Que informa

- Version de Node.js.
- Plataforma del sistema.
- Argumentos recibidos por la terminal.
- Variable de entorno `USERNAME`.

## Evidencia

La evidencia de ejecucion esta guardada en `evidencia.txt`.
